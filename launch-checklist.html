Data Persistence (Beyond localStorage)
LATER
  • Decide on a database
    Right now all data lives in stratusWR_v31 in localStorage — one browser, one device. For multi-device sync you need a DB. Recommended: Supabase (Postgres, free tier), or keep localStorage and add optional export/import.
  • Add a sync/save API endpoint
    Create a POST /api/save and GET /api/load route that reads/writes the user's data blob. The app already serialises everything as a single JSON object — pipe that to the DB.
  • Wire the app's save/load to use the API
    Replace (or augment) the localStorage.setItem('stratusWR_v31', ...) calls in the app with fetch calls to your new API. Keep localStorage as an offline cache.
4
AXIS AI Integration
LATER
  • Get an OpenAI (or compatible) API key
    AXIS makes calls with Authorization: Bearer <apiKey>. The user currently pastes their own key in the app settings. For production, proxy calls through your own backend so the key stays server-side.
  • Create an API proxy route
    Add a POST /api/axis serverless function that forwards the request to OpenAI with your secret key. This protects your key and lets you add rate-limiting per user.
  • Pass user data context to AXIS
    For AXIS to answer questions about "your actual P&L", the app needs to inject the user's data as system context in the API call. Pipe the stratusWR_v31 blob (or a summary of it) into the system prompt.
5
Deployment
LATER
  • Deploy to Netlify
    Push this branch to GitHub, then go to app.netlify.com → Add new site → Import from Git. Set publish directory to . (root). index.html serves at / and app.html at /app.html automatically. The netlify.toml already in the repo sets security headers and publish dir.
  • Point a custom domain
    Netlify dashboard → Site settings → Domain management → Add custom domain. Netlify provisions SSL via Let's Encrypt automatically — just point your DNS records as instructed.
  • Add environment variables for secrets
    Store API keys in Netlify → Site settings → Environment variables. Never commit them to the repo. Access them in Netlify Functions via process.env.MY_KEY. Add a netlify/functions/ folder when you're ready to add serverless routes (AXIS proxy, auth API, etc.).
  • Test the full flow end-to-end
    Visit your domain → sign up → get redirected to /app.html → create a mission → refresh → data persists. Also test: sign out, direct-navigate to /app.html while logged out → should redirect to /.
